# Chat Application (Client–Server)

## 📌 Overview
This project is a secure Chat Application developed using Python based on a client–server architecture. It allows multiple users to communicate in real time through a graphical interface.

## 🛠 Technologies Used
- Python
- socket
- threading
- Tkinter
- base64 (for basic encryption)

## ✨ Features
- Real-time messaging
- Client–server architecture
- Username-based login
- GUI-based chat interface
- Basic message encryption
- Multithreaded server handling multiple clients

## ▶ How to Run
1. Start the server:
   ```bash
   python server.py

Start the client (run multiple times for multiple users):
    python client.py
